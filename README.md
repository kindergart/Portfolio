# 个人作品集网站

这是一个现代化的响应式个人作品集网站，用于展示个人项目、技能和专业经历。

## 🌟 项目特色

- **响应式设计**：适配各种设备尺寸，从手机到桌面电脑
- **现代UI/UX**：采用渐变色彩和卡片式布局，提供优秀的视觉体验
- **交互功能**：平滑滚动、动画效果、表单验证等丰富的用户交互
- **性能优化**：使用现代CSS和JavaScript技术，确保快速加载
- **易于定制**：模块化的代码结构，便于修改和扩展

## 📁 项目结构

```
lab04/
├── index.html          # 主页面文件
├── styles.css          # 样式文件
├── main.js            # JavaScript交互功能
├── images/            # 图片资源文件夹
│   ├── profile-placeholder.jpg  # 个人资料图片占位符
│   ├── project1.jpg   # 项目1展示图片
│   ├── project2.jpg   # 项目2展示图片
│   └── project3.jpg   # 项目3展示图片
├── .trae/
│   └── rules/
│       └── project_rules.md  # 项目规则配置
└── README.md          # 项目说明文档
```

## 🚀 功能特性

### 页面结构
- **首页**：欢迎区域，包含个人介绍和行动号召按钮
- **关于我**：个人信息和专业背景介绍
- **项目展示**：项目作品展示区域，包含项目图片和链接
- **技能展示**：技能分类展示，包含前端、后端和其他技能
- **联系方式**：联系表单和联系信息

### 交互功能
- **平滑滚动**：点击导航链接平滑滚动到对应区域
- **响应式导航**：移动端友好的汉堡菜单
- **表单验证**：联系表单的实时验证功能
- **滚动动画**：页面滚动时的元素动画效果
- **通知系统**：用户友好的操作反馈通知

### 设计特点
- **现代渐变**：使用CSS渐变创造现代化的视觉效果
- **卡片布局**：项目展示采用卡片式设计
- **悬停效果**：丰富的鼠标悬停交互效果
- **响应式网格**：自适应的网格布局系统

## 🛠️ 技术栈

- **HTML5**：语义化的页面结构
- **CSS3**：现代CSS特性，包括Flexbox和Grid布局
- **JavaScript (ES6+)**：原生JavaScript实现交互功能
- **SVG**：矢量图形占位符

## 📱 响应式设计

网站采用移动优先的设计理念，支持以下设备尺寸：
- **手机**：≤ 480px
- **平板**：481px - 768px
- **桌面**：≥ 769px

## 🎯 使用方法

### 本地开发

1. **克隆项目**（如果有版本控制）:
   ```bash
   git clone [项目地址]
   cd lab04
   ```

2. **直接打开文件**:
   由于这是一个静态网站，您可以直接在浏览器中打开 `index.html` 文件。

3. **使用Live Server**（推荐）:
   - 如果您使用VS Code，可以安装 "Live Server" 扩展
   - 右键点击 `index.html` 文件，选择 "Open with Live Server"
   - 浏览器将自动打开并实时刷新页面

### 自定义内容

1. **个人信息**：修改 `index.html` 中的个人信息部分
2. **项目内容**：更新项目展示区域的内容和图片
3. **技能列表**：根据个人技能修改技能展示部分
4. **样式定制**：在 `styles.css` 中修改颜色、字体等样式
5. **交互功能**：在 `main.js` 中添加或修改JavaScript功能

### 添加真实图片

将您的真实图片文件替换 `images/` 文件夹中的占位图片：
- `profile-placeholder.jpg` → 您的个人照片
- `project1.jpg`, `project2.jpg`, `project3.jpg` → 您的项目截图
